Two faces, one crawler

greenfinger-cli.sh runs the same engine from a terminal, with no server and no login. greenfinger-api.sh is what this page talks to. Both read the same configuration, so a setting means the same thing whichever one is running.

Two roles

Administrator creates catalogs and runs crawl, update, rebuild and delete. Support reads everything and changes nothing. Accounts are handed out up front, in the server's .env.
